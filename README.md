# Тук — офлайн-помощник для Windows и Android

Маленький анимированный помощник в строке у верхнего края экрана. Записывает задачи, напоминания, показатели здоровья и заметки по обычным русским фразам. Работает без интернета, ПК и телефон синхронизируются по домашнему Wi-Fi.

Версия 0.1 — без нейросети: фразы разбираются правилами. Нейросеть и голос — следующий этап.

## Что умеет

| Напишите | Что произойдёт |
| --- | --- |
| напомни завтра в 9 позвонить поставщику | напоминание на завтра 9:00 |
| напомни через 10 минут выключить чайник | напоминание через 10 минут |
| каждый день в 21 выпить таблетки | ежедневное напоминание, помечено «здоровье» |
| по будням в 8:30 планёрка | напоминание пн–пт |
| запиши купить кабель ВВГ 3×2,5 | задача без срока |
| в пятницу сдать отчёт | задача на пятницу |
| давление 130 на 85 пульс 72 | две записи здоровья |
| спал 7 часов · выпил стакан воды · вес 82,4 · самочувствие хорошо | записи здоровья |
| заметка: щит 600×800 | заметка |
| готово кабель · удали хлеб · что на сегодня | отметить, удалить, сводка |

Персонаж показывает настроение: **спит** без дела, **слушает**, когда вы печатаете, **думает**, **записывает**, **добрый** — после выполненного дела, **напоминает** — когда сработало напоминание, **злой** — если напоминание просрочено больше 10 минут. Состояние «встреча» пока можно посмотреть только в ⚙ — функция «кто рядом» будет в следующей версии.

Голосом уже можно пользоваться через микрофон на клавиатуре Samsung или Windows (Win+H): он вводит текст, а Тук его разбирает.

## Сборка без установки программ — через GitHub

В проекте есть сценарий `.github/workflows/build.yml`: GitHub сам собирает APK и установщик для Windows.

1. Зарегистрируйтесь на https://github.com и создайте репозиторий (кнопка **New**, например `tuk`, можно приватный).
2. На странице репозитория: **Add file → Upload files**, перетащите туда всё содержимое папки `tuk` (вместе с папкой `.github`) и нажмите **Commit changes**.
3. Откройте вкладку **Actions** — сборка начнётся сама и займёт 15–25 минут.
4. Когда появится зелёная галочка, откройте запуск и внизу, в разделе **Artifacts**, скачайте **Tuk-Android-APK** (и **Tuk-Windows-setup** для ПК). Внутри архива — `app-universal-debug.apk`.
5. Перекиньте APK на телефон и установите.

## Разговор с нейросетью

Тук умеет поддерживать разговор: вкладка **«Чат»** или просто напишите что-нибудь без команды («как дела?», «что у меня завтра?», «помоги спланировать день»). Он знает ваши дела, напоминания, заметки и последние записи здоровья.

- Мозг — локальная нейросеть Qwen3 (llama.cpp в WebAssembly через [wllama](https://github.com/ngxson/wllama)). Скачивается один раз с Hugging Face по кнопке «Скачать мозг», дальше работает без интернета.
- «Лёгкий» — Qwen3 1.7B, 1,1 ГБ, по умолчанию на телефоне. «Умный» — Qwen3 4B Instruct, 2,1 ГБ, по умолчанию на ПК. Переключается в ⚙ → Мозг.
- Телефон, связанный с ПК, по умолчанию спрашивает «Умный» мозг ПК; вне дома — свой. Своего может и не быть — тогда разговор работает только рядом с ПК.
- Команды («напомни…», «запиши…», «давление…») и фразы, начинающиеся с действия («купить хлеб»), по-прежнему записываются сразу, без нейросети.
- История разговора хранится только на этом устройстве.

## Персонаж, гардероб, файлы, сводка

- **Эмоции и звуки.** При запуске Тук машет, после долгого бездействия засыпает, а когда его будят — машет снова. Тычок в персонажа — «Ой!», три быстрых тычка — кружится голова. Звуки синтезируются в коде; громкость — в ⚙.
- **Гардероб.** ⚙ → Гардероб: шарф, новогодняя шапка, тёмные очки, наушники, тыква, венок, бабочка, корона или «по сезону» (наряд меняется сам). Там же цвет капюшона и цвет огонька в покое.
- **Файлы на Тука.** Перетащите файл на окно или нажмите 📎. Тук «глотает» его и отвечает на вопросы о содержимом (текстовые файлы и PDF с текстом; первые 6000 символов).
- **Недельная сводка.** По понедельникам на вкладке «Сегодня» появляется карточка; в любой день — ⚙ → «Сводка за неделю». Картинка 1080×1920 сохраняется в «Изображения».

## Питомец, музыка, Claude Code (ПК)

- **Тук на рабочем столе.** ⚙ → «Питомец» или пункт в трее. Отдельное прозрачное окно поверх всех: перетаскивается мышью, глаза следят за курсором, клик — «Ой!», двойной клик — вернуть в строку. Место запоминается.
- **Музыка в строке.** Если что-то играет (Spotify, Яндекс Музыка в браузере, YouTube, любой плеер Windows), в строке видно трек, а на «Сегодня» есть обложка и кнопки ⏮ ⏯ ⏭. Тук пританцовывает; это отключается в ⚙ → «Музыка».
- **Claude Code.** ⚙ → «Claude Code» → «Подключить». Тук добавляет свои хуки в `~/.claude/settings.json`, ваши настройки и хуки не трогает (копия сохраняется в `settings.json.tuk-backup`). Перезапустите Claude Code. На вкладке «Агенты» видно, что агент читает и правит (+/− строк). Когда он просит разрешения, Тук тревожится и показывает кнопки «Разрешить», «Всегда в этом проекте» и «Запретить». Те же кнопки появляются на связанном телефоне, там нужно подтвердить отпечатком. Если за 110 секунд никто не ответил, Claude Code спросит в терминале как обычно. Хуки принимаются только с этого же компьютера.

## Тук на телефоне: остров, «Тук Тук» и голос (Android)

- **Остров.** ⚙ → «Тук над приложениями» → «Включить», затем разрешите «Поверх других приложений». Тук в полный рост живёт вверху экрана поверх любых приложений и рабочего стола. Его можно перетащить куда удобно, место запомнится. Облачко с текстом появляется рядом, только когда есть что сказать.
- **Нажатие** открывает небольшое окно поверх текущего экрана: строка ввода, 🎤, «Сегодня», «Чат», «Дела», «Напоминания». Нажатие мимо окна закрывает его, ⤢ открывает всё приложение. **Долгое нажатие** сразу открывает приложение.
- **«Тук Тук».** ⚙ → «Тук Тук — голосом» → «Скачать и включить». Один раз скачивается русская модель распознавания, около 45 МБ. После этого Тук слушает постоянно и без интернета, а откликается только на «Тук Тук»: пищит, слушает команду, выполняет её и отвечает голосом. Можно сказать всё сразу: «Тук Тук, напомни через час позвонить». Пока он слушает, Android показывает значок микрофона. Звук никуда не отправляется.
- **Эмоции сами по ситуации.** Тук сам меняет позу по тому, чем занят:

  | Поза | Когда |
  |---|---|
  | Думает | рука у подбородка, облачко «…» — разбирает вопрос |
  | Работает | за ноутбуком — пишет ответ |
  | Слушает | в наушниках — вы печатаете или говорите |
  | Ищет | с лупой — ищет дело, читает файл, Claude Code читает код |
  | Готов | с планшетом — ответил и ждёт следующую задачу |
  | Помогает | показывает список — сводка, подсказки |
  | Выполняет | несёт коробки — синхронизация, Claude Code запускает команды |
  | Отдыхает | лежит рядом с кружкой — давно не трогали |
  | Рядом | выглядывает из-за кружки — тихо, но он здесь |
  | Уходит в фон | вид со спины — свернули приложение |

## Голос и команды

- **Живой голос Тука** (телефон): ⚙ → «Голос Тука». Это нейросетевой синтез речи прямо на телефоне, без интернета. Есть пять голосов: «Тук» (по умолчанию), «Звонкий», «Мальчишка», «Спокойный» и «Системный». Голос скачивается один раз, около 67 МБ.
- **Тук выполняет команды** — голосом («Тук Тук, …» или 🎤) или текстом:

  | Что сделать | Как сказать |
  |---|---|
  | Будильник | «поставь будильник на семь утра», «разбуди в половину седьмого», «будильник по будням на 6:45» |
  | Таймер | «таймер на пять минут», «засеки полчаса» |
  | Звонок | «позвони маме», «набери Сашу Иванова», «позвони на номер 8 900 …». Если подходят несколько контактов, Тук спросит «Кому именно?», и можно ответить «второй» |
  | Сообщение | «напиши маме, что я задержусь на час» — откроется готовое SMS |
  | Приложения | «открой телеграм», «запусти ютуб», «открой камеру». На ПК: «открой блокнот», «открой диспетчер задач», «открой habr.com» |
  | Телефон | «включи фонарик», «громче», «тише», «выключи звук», «следующий трек», «пауза», «сколько заряда» |
  | Маршрут и поиск | «проложи маршрут до вокзала», «найди в интернете рецепт борща» |
  | Календарь | «добавь в календарь встречу с поставщиком завтра в 15» |
  | Время | «который час», «какое сегодня число» |

- **Мозг на телефоне** теперь работает нативно (llama.cpp): модель читается с диска, а не загружается в память встроенного браузера, поэтому приложение больше не закрывается. После обновления мозг нужно скачать заново: ⚙ → «Мозг» → «Скачать». Старая копия удаляется сама и освобождает место.

## Что установить (один раз, на Windows)

1. **Node.js 20 или новее** — https://nodejs.org
2. **Rust** — https://rustup.rs (при установке согласитесь поставить Visual Studio Build Tools с «Разработка классических приложений на C++»).
3. **WebView2** уже есть в Windows 10/11.

Для телефона дополнительно:

4. **Android Studio** — https://developer.android.com/studio. В нём: Settings → Languages & Frameworks → Android SDK → вкладка SDK Tools → отметьте **NDK (Side by side)** и **Android SDK Command-line Tools**.
5. Переменные среды Windows (Пуск → «Изменить переменные среды»):
   - `JAVA_HOME` = `C:\Program Files\Android\Android Studio\jbr`
   - `ANDROID_HOME` = `%LOCALAPPDATA%\Android\Sdk`
   - `NDK_HOME` = `%ANDROID_HOME%\ndk\<номер версии>` (папка внутри `Sdk\ndk`)
6. В PowerShell:
   ```
   rustup target add aarch64-linux-android armv7-linux-androideabi i686-linux-android x86_64-linux-android
   ```

Подробно с картинками: https://v2.tauri.app/start/prerequisites/

## Сборка

В папке проекта:

```
npm install
npm test
```

`npm test` проверяет разбор фраз и синхронизацию — должно быть 14 из 14.

### ПК (Windows)

```
npm run tauri dev
```
Откроется строка вверху экрана — так удобно проверять. Установщик:
```
npm run tauri build
```
Готовый файл: `src-tauri\target\release\bundle\nsis\Tuk_0.1.0_x64-setup.exe`.

Первая сборка идёт 5–15 минут — Rust скачивает и компилирует библиотеки, дальше быстрее.

### Телефон (Galaxy S24 Ultra)

```
npm run tauri android init
npm run tauri icon src-tauri/icons/app-icon.png
npm run tauri android build -- --apk --debug --target aarch64
```
Готовый файл: `src-tauri\gen\android\app\build\outputs\apk\universal\debug\app-universal-debug.apk`. Перекиньте его на телефон и установите (Samsung попросит разрешить установку из этого источника).

Отладочная сборка подписана тестовым ключом — для себя этого достаточно. Подписанная релизная сборка: https://v2.tauri.app/distribute/sign/android/

Можно и без файла: включите на телефоне «Отладку по USB», подключите кабелем и запустите `npm run tauri android dev`.

## Первый запуск и связь ПК ↔ телефон

1. **ПК.** При первом запуске Windows спросит про брандмауэр — разрешите доступ в **частных сетях**. Строка: наведите мышь — раскроется, клик — полная панель, **Ctrl+Alt+Пробел** — открыть/свернуть, Esc — свернуть. Значок в трее: «Открыть», «Связь с телефоном», «Выход».
2. **Телефон.** Разрешите уведомления.
3. ПК и телефон должны быть в одной сети Wi-Fi.
4. На ПК: ⚙ → QR-код. На телефоне: ⚙ → **«Сканировать QR-код с ПК»** (разрешите камеру).
   Без камеры: на ПК «Код из 6 цифр», на телефоне «Найти ПК в сети» → выбрать ПК → ввести код.
5. Готово: внизу появится зелёная точка и «ПК · только что».

Чтобы Samsung не закрывал Тук: Настройки → Приложения → Tuk → Батарея → **Без ограничений**; Настройки → Обслуживание устройства → Батарея → Ограничения фонового использования → «Приложения, которые никогда не переводятся в спящий режим» → добавить Tuk.

## Как это устроено

```
src/              интерфейс и вся логика (TypeScript)
  parser.ts       разбор русских фраз → задача / напоминание / здоровье
  character.ts    персонаж и анимации (Canvas)
  sync.ts         протокол синхронизации («последняя правка побеждает»)
  crypto.ts       шифрование AES-GCM, ключ из PIN через PBKDF2
  qr.ts           генератор QR-кода
  link.ts         связь: ПК — сервер, телефон — клиент
  reminders.ts    срабатывание, «отложить», уведомления Android по расписанию
  app.ts          строка, панель, вкладки
src-tauri/        Rust-часть (Tauri 2)
  src/lib.rs      файл данных, окно-строка, трей, горячая клавиша, команды
  src/net.rs      HTTP-сервер и клиент, UDP-маяк — только стандартная библиотека Rust
tests/            тесты разбора фраз и синхронизации
```

- Данные: на ПК `%APPDATA%\ru.tuk.assistant\tuk-data.json` (рядом резервная копия `.bak`), на телефоне — в папке приложения.
- Сеть: ПК слушает TCP-порт **47800** и раз в 3 секунды шлёт UDP-маяк на порт **47801**. Всё содержимое зашифровано общим ключом из QR-кода; без ключа данные не прочитать.
- Напоминания на телефоне ставятся системными уведомлениями Android — сработают, даже если Тук закрыт.

## Ограничения версии 0.1

- Нет встроенного распознавания речи — следующий этап плана (пока — микрофон клавиатуры).
- На телефоне нет «пузыря поверх других приложений»: Тук живёт в своём окне и в уведомлениях. Пузырь — отдельный нативный модуль на Kotlin, следующий этап.
- Телефон синхронизируется, пока Тук открыт (сразу после правки и каждые 20 секунд). Напоминания при этом срабатывают всегда.
- Поиск ПК по сети работает не на всех роутерах — тогда введите IP ПК вручную (он написан под QR-кодом).
- «Отложить» у повторяющегося напоминания действует только на том устройстве, где нажали.
- Код Rust-части не компилировался там, где его писали (не было доступа к библиотекам). Сетевой модуль проверен отдельно, но если `tauri build` выдаст ошибку — пришлите её текст, поправлю.

## Что проверено перед передачей

- 14 тестов (больше 60 проверок): разбор русских фраз, синхронизация в обе стороны, конфликты правок, удаление, второй телефон, шифрование, сопряжение по PIN.
- 5 тестов Rust-сети: обмен через HTTP с телом 650 КБ, тайм-аут без зависания, поиск ПК по UDP-маяку.
- QR-коды версий 1–20 читаются OpenCV.
- Сквозной тест в Chromium: копия «ПК» и две копии «Android» связываются по QR и по PIN, обмениваются задачами, отметками и удалениями, телефоны ставят системные уведомления, ПК показывает уведомление и раскрывает строку.
