# Тук 0.2 — ТЗ «идеального помощника»

Ориентир — Coucou (https://github.com/Louis-CFM/coucou, MIT; ассеты под отдельной лицензией — их НЕ копируем, только идеи и приёмы). Тук остаётся собой: свой персонаж (чёрный капюшон с антенной-огоньком, белая маска с большими глазами, куртка и рюкзак с «Т»), русский язык, офлайн, локальный мозг.

## 1. Жалобы пользователя (что чиним в первую очередь)

1. **Баг окна (скриншот):** на рабочем столе Windows висит большое тёмное прямоугольное окно ~440×640, в центре крошечный Тук. Окно должно быть прозрачным: на экране только персонаж/остров, никакого тёмного прямоугольника.
2. **Нельзя сделать окно прозрачным** — нужен по-настоящему прозрачный остров + click-through вне видимых элементов (клики проходят на рабочий стол).
3. **Анимация хромает** — рывки, мелкий размер, нет плавных переходов.
4. **Плохо работает с файлами.**
5. **Сложно с несколькими процессами** (несколько сессий Claude Code / агентов одновременно).
6. **Половины функций Coucou нет; многие функции «закрыты»** (спрятаны, недоступны, требуют неочевидных шагов).

## 2. Идеальный помощник — пользовательский опыт

### Остров (ПК, Windows)
- Машина состояний как у Coucou: `hidden → peek → home`. В покое у верхнего края видна только маленькая «капсула» с Туком (или вовсе ничего — настройка). Наведение — выглядывает (peek), клик — раскрывается (home), клик мимо/Esc — сворачивается. Переходы — пружинные, 60 fps, без мигания фона.
- Окно прозрачное всегда; фон рисует только сам остров (скруглённая капсула/панель). Вне острова — click-through.
- Не отнимает фокус в свёрнутом виде. Мульти-монитор: закрепить за экраном или «следовать за мышью».
- Горячая клавиша — открыть/закрыть, ввод сразу в фокусе.

### Питомец на рабочем столе
- Вытащить Тука из острова мышью → он становится свободным компаньоном (~120 px), окно ровно по размеру персонажа, полностью прозрачное, без тёмного фона.
- Следит глазами за курсором, «летит» к острову при тревоге и возвращается, помнит место.

### Анимация персонажа (главное «лицо» продукта)
- Рендер Canvas 2D на requestAnimationFrame, 60 fps, с учётом devicePixelRatio (чёткость на 125–200 % масштабе).
- Дыхание, моргание по случайному таймеру, глаза «на сфере» следят за курсором.
- Пружинная физика (spring) для всех переходов позы; squash & stretch при прыжке/тычке.
- Наведение — моргает и глаза растут. Клик — сплющивается + эмоция. Три клика — головокружение. Задача выполнена — радостный прыжок. Тревога — подпрыгивает и мигает огонёк. Музыка — танцует в такт. Файл перетащили — открывает рот-коробку и «глотает».
- Плавное смешивание поз (cross-fade/интерполяция), а не мгновенная смена кадра.
- Экономия: при скрытом окне/неактивности — 10–15 fps или пауза.

### Файлы
- Нативный drag & drop Tauri (`onDragDropEvent`) на остров и на питомца — работает и для файлов из Проводника.
- Форматы: txt/md/csv/json/log/xml/yaml/ini/srt, PDF (текст), DOCX, XLSX (первые листы в текст), изображения (превью + имя/размер), прочее — карточка «имя, размер, путь».
- Несколько файлов сразу; лимит текста разумный, с явным сообщением, что обрезано.
- Действия с файлом: спросить о содержимом, сделать заметку/задачу из файла, «открыть», «показать в папке».

### Несколько процессов / агентов
- Каждая сессия Claude Code (и другие агенты по хукам) — своя «пилюля» своего цвета: проект, текущий шаг (чтение/правка/команда), +N/−M.
- Очередь запросов разрешений из нескольких сессий одновременно, без потери и перепутывания; `AskUserQuestion` с вариантами.
- Завершённые/зависшие сессии убираются по таймауту; можно закрыть вручную.

### Открытость функций
- Ничего важного не прячется за неочевидными настройками: в раскрытом острове видны вкладки, в ⚙ — понятные разделы. Первый запуск — короткий онбординг (3 экрана) с включением питомца, хоткея, мозга.
- Демо-режим, чтобы посмотреть все состояния и анимации без настройки.

### Android (Galaxy S24 Ultra)
- Остров поверх приложений с той же анимацией (тот же character.ts в WebView или нативный порт), без тёмной подложки.

## 3. Качество
- `npm test` зелёный; новые тесты на машину состояний острова, очередь разрешений нескольких сессий, разбор файлов.
- `tsc` без ошибок. CI на GitHub собирает APK и установщик Windows.
- Ручной чек-лист тестировщика в `docs/QA.md`: прозрачность, click-through, DPI 100/125/150/200 %, два монитора, drag&drop из Проводника, 3 параллельные сессии Claude Code.

## 4. Команда и зоны ответственности (кто какие файлы правит)
- **Дизайнер-аниматор:** `src/character.ts`, `src/pet.ts`, `src/sounds.ts`, `src/styles.css` (визуал острова), демо-страница анимаций `src/demo.html`.
- **Программист ПК (Rust/Tauri):** `src-tauri/**`, `src/platform.ts`, остров/окна, прозрачность, click-through, drag&drop, хоткей, мульти-монитор.
- **Программист функций (TS):** `src/files.ts`, `src/agents.ts`, `src/app.ts` (UI вкладок, онбординг, открытость функций), `src/link.ts`.
- **Тестировщик:** `tests/**`, `docs/QA.md`, проверка сборки, ревью; правки в чужих файлах — только через сообщение владельцу.
