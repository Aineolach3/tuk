# Coucou и Тук: сравнение функций

Сверено с README Coucou (Windows 0.5, Android 0.2) на 19.10.2026. Код Coucou — MIT; имя, персонаж Mochi и звуки Coucou не используем.

Обозначения: **есть** — было до 0.2; **сделано** — сделано в этой итерации; **позже** — реально, но не сейчас; **не будет** — противоречит идее Тука (офлайн, без облака, без аккаунтов) или не имеет смысла.

## Агенты (Claude Code и другие)

| Функция Coucou | Тук | Комментарий |
|---|---|---|
| Сессии Claude Code в строке: что читает, правит, запускает | есть | вкладка «Агенты» |
| Каждая сессия — своя пилюля своего цвета | **сделано** | 8 цветов, у одновременных сессий не повторяются; проект, текущий шаг, +N/−M за запрос, длительность |
| Другие агенты (Codex, Gemini CLI, Cursor…) | **сделано** (приём) | поле `tuk_agent` / `coucou_agent` в событии хука → своя пилюля и цвет агента. Готовых хуков под каждого агента пока нет — **позже** |
| Allow / Deny / Always | есть | «Всегда» — на проект; правила теперь видно и можно удалить в ⚙ → «Агенты» |
| Несколько запросов разрешений одновременно | **сделано** | очередь: у каждого запроса свой reqId и цвет сессии, отвечать можно в любом порядке. Coucou в этом случае отдаёт второй запрос в терминал — у Тука лучше |
| Карточка уходит, если ход закончился (ответили в терминале, Stop, новый запрос) | **сделано** | как в Coucou: запрос отпускается без решения |
| `AskUserQuestion` с вариантами (один / несколько, до 4 вопросов) | **сделано** | ответ уходит как `updatedInput.answers`, ответ проверяется по вариантам; «Отвечу в терминале» |
| Таймаут разрешения (~110 с) — вопрос возвращается в терминал | есть → **переделано** | теперь общей уборкой `sweep()`, без отдельных таймеров |
| Авто-удаление закончивших / зависших сессий | **сделано** | закончившие — 30 мин, «молчит» после 10 мин без событий, убирается через час, закрытые — через минуту; отключается галочкой |
| Закрыть сессию вручную | **сделано** | × у сессии, «Убрать закончившие»; работает и с телефона |
| Последний ответ агента (Stop) | **сделано** | показывается под шагами |
| Живой diff по клику | позже | нужен буфер правок; сейчас только +N/−M |
| Перейти в терминал сессии | не будет (пока) | на Windows нет надёжного способа найти окно терминала без нативного кода; задача программиста ПК |
| Лимиты плана Claude / Codex | не будет | требует сетевых запросов к облаку |
| Разрешение с телефона по отпечатку | есть | теперь и ответы на вопросы, и закрытие сессий с телефона (`/agent-answer`, `/agent-close`) |
| Горячие клавиши (разрешить / открыть) | **сделано** | Ctrl+Enter — разрешить первый запрос, Ctrl+Backspace — запретить, Alt+1…8 — вкладки, Ctrl+O — файлы, `?` — подсказка |

## Файлы

| Функция Coucou | Тук | Комментарий |
|---|---|---|
| Бросить файл на остров, Mochi «глотает» | есть | анимация `eat` |
| Несколько файлов сразу | **сделано** | до 8; бюджет текста для мозга делится между ними (короткие целиком, длинные поровну) |
| Форматы | **сделано** | txt/md/csv/tsv/json/log/xml/yaml/ini/srt/vtt/код, HTML → текст; кодировки UTF-8, UTF-16, Windows-1251; PDF (pdf.js); **DOCX, XLSX, PPTX** — свой разбор zip через `DecompressionStream('deflate-raw')` без новых пакетов |
| Картинки | **сделано** | карточка с превью, размер в пикселях. Содержимое картинок мозг не видит — локальная модель текстовая |
| Прочее | **сделано** | карточка «имя, размер, путь» |
| Явно сказать, что текст обрезан | **сделано** | «Мозгу ушло только начало: N из M символов» в карточке и в ответе |
| Спросить о файле | есть → **улучшено** | кнопка «Перескажи» и свободные вопросы о нескольких файлах |
| Сделать заметку / задачи из файла | **сделано** | задачи — из чек-листов `- [ ]`, TODO:, нумерованных и маркированных списков |
| Открыть / показать в папке | **сделано** (UI) | для файлов из Проводника с путём; нужен нативный drop — см. HANDOFF |
| Отправить файл письмом | не будет | Тук не отправляет почту; заметка и связь с телефоном вместо этого |
| Перетащить окно как контекст | не будет | только macOS у Coucou |

## Разговор и мозг

| Функция Coucou | Тук | Комментарий |
|---|---|---|
| Чат с Claude / Gemini / OpenAI / DeepSeek… по своему ключу | не будет | облачные API противоречат офлайн-идее и требуют аккаунтов |
| Локальная модель (Ollama / LM Studio) | **сделано** | ⚙ → «Мозг»: адрес, «Проверить», выбор модели, потоковый ответ через `/v1/chat/completions`. Разрешены только localhost и частные сети |
| Встроенный мозг без сервера | есть (у Coucou нет) | Qwen3 1,7B / 4B, llama.cpp |
| Диктовка в чат | есть | 🎤; на Android — «Тук Тук» |
| «OK Coucou» голосом | есть (Android) | «Тук Тук», распознавание на устройстве; на ПК — позже |
| Flow-диктовка в любое поле, Notetaker | позже / не будет | требуют нативного захвата звука и большой модели речи; Notetaker пишет звонки — вне задач Тука |

## Открытость функций

| Функция Coucou | Тук | Комментарий |
|---|---|---|
| Демо-режим | **сделано** | две параллельные сессии, разрешение, вопрос, файл, все 21 состояние персонажа; ничего не пишет на диск. ⚙ → «Справка и демо», вкладка «Агенты», знакомство |
| Понятные настройки | **сделано** | ⚙ разбит на разделы: Основное, Внешний вид, Мозг, Связь, Агенты, Компьютер/Телефон, Справка и демо |

### Что было «закрыто» и как открыто

| Было | Стало |
|---|---|
| Вкладка «Агенты» скрыта (`hidden`), пока не подключён Claude Code | видна всегда; внутри — «Подключить Claude Code» и «Посмотреть демо»; счётчик ждущих запросов на вкладке |
| ⚙ доступна только в раскрытой строке на ПК (в свёрнутой кнопка спрятана) | ⚙ ещё и последней вкладкой рядом с остальными |
| Все настройки одной длинной лентой; питомец, Claude Code, музыка — в её середине | разделы с навигацией; «Агенты» и «Справка и демо» — отдельно |
| Скрепка принимала только txt/md/csv/json/log/pdf/html/xml/yaml/ini/srt и один файл | любые файлы, несколько сразу |
| Ollama / LM Studio — не было | раздел «Мозг» |
| Правила «Разрешать всегда» нельзя посмотреть и удалить | список в ⚙ → «Агенты» |
| Горячая клавиша упоминалась одной строкой | знакомство, ⚙ → «Основное», подсказка по `?` |
| «помощь» давала одну фразу | ещё и открывает ⚙ → «Справка и демо» со списком возможностей |
| Ответ на вопрос агента и закрытие сессии с телефона — не было | `/agent-answer`, `/agent-close` |

Оставшиеся заглушки: «Громкость на ПК пока регулируйте клавишами» (нужна команда в Rust), «Перейти в терминал» (нет).
